# 메리츠증권 Trading MCP (설치 안내)

메리츠증권이 공식 배포하는 MCP 서버의 설치 방법과 사용 시 유의 사항을 정리한 문서입니다. 이 저장소에서 구현한 서버가 아니므로 배포 파일은 포함하지 않습니다.

| 항목 | 내용 |
|---|---|
| 배포처 | 메리츠증권 Open API 포털(openapi.imeritz.com)의 MCP 안내 페이지와 공식 GitHub |
| 배포 파일 | macOS Apple Silicon `meritz-open-api-darwin-arm64.mcpb`, macOS Intel `…-darwin-x64.mcpb`, Windows `…-win32-x64.mcpb` |
| 인증 | APP KEY, APP SECRET (설치 화면에서 입력) |

파일 이름에 `codegen`이 들어간 것은 다른 도구입니다.

## 설치 (Claude Desktop)

1. Open API 포털 또는 앱에서 APP KEY와 SECRET을 발급받습니다. 실계좌에 연결된 키이므로 외부에 노출하지 마세요.
2. `.mcpb` 파일을 Claude Desktop의 설정 > 확장 프로그램에 끌어다 놓습니다.
3. 설치 화면에 키를 입력하고 **'조회 전용' 옵션을 켭니다.** 이 옵션을 끄면 주문과 환전이 가능해집니다.
4. 확장을 사용 상태로 바꾸고 Claude Desktop을 다시 시작합니다.

## 주요 조회 코드

2026-11-04에 실제 조회로 확인한 코드입니다.

| 구분 | 코드 |
|---|---|
| 국내 지수 | 코스피 `KGG01P`, 코스닥 `QGG01P`, 코스피200 `K2G01P`. 업종지수도 같은 형식 (예: 음식료·담배 `KGS01P`) |
| 해외 지수 | 나스닥 `NAS@IXIC`, S&P500 `SPI@SPX`, 다우 `DJI@DJI`, 필라델피아 반도체 `NAS@SOX` |
| 선물·원자재 | 나스닥100 선물 `CME@NQ`, S&P500 선물 `CME@ES`, WTI `NYM@CL`, 달러인덱스 `ETC@DXY00` (시장 구분 `N`) |
| 환율 | 원/달러 `USDKRWSMBS` |
| EWY (미국 상장 한국 ETF) | 거래소 코드 `AX` + 티커 `EWY` (`NY`로는 빈 값 반환). 정규장·애프터마켓·주간거래 가격 조회 가능 |

## 데이터 기준과 제약

| API | 유의 사항 |
|---|---|
| 종목 일봉 `market_candles_days` (기본 `TJ`) | 종가가 KRX 정규장 공식 종가입니다. 외국인·기관 순매수 수량은 토스증권 Open API 값과 일치했습니다. |
| 종목 현재가 `market_prices` (`J`) | NXT 애프터마켓 이후 가격이 반영되므로 공식 종가가 아닙니다. |
| 종목별 투자자 `market_investors` | 장중 특정 시점의 값에 머물러 있고 전일 행이 당일 값으로 덮어써지는 현상이 있어 사용을 권장하지 않습니다. |
| 지수 현재가의 상승·하락 종목 수 | 시간외 거래까지 반영되어 20시 무렵까지 값이 바뀝니다. |
| WTI, 달러인덱스 | 전일 정산값이 제공되며 장중 실시간 값이 아닙니다. |

- 미국 국채 금리, VIX, 시장 전체 투자자별 수급은 제공되지 않습니다.
- 로컬 확장이므로 Claude Desktop이 실행 중일 때만 사용할 수 있습니다.
