# 파일

- [금융감독원 DART 서버 (dart)](dart.md) - dart-readonly 서버가 회사 지정을 고유번호로 바꾸는 방식, 외부 패키지 없이 zip을 푸는 방식, 공시·재무·주요사항 도구의 구성과 DART 상태 코드 처리를 설명한다.
- [한국은행 ECOS 서버 (ecos)](ecos.md) - ecos-readonly 서버가 ECOS의 경로형 주소를 만드는 방식, 시장금리 묶음 도구의 스프레드 계산, 통계표 코드를 찾는 흐름과 주기별 날짜 검증을 설명한다.
- [SEC EDGAR 서버 (edgar)](edgar.md) - edgar-readonly 서버가 키 없이 User-Agent로 SEC에 접근하는 방식, 회사 지정을 CIK로 바꾸는 방식, XBRL 사실 값을 연간·분기 시계열로 정리하는 규칙, 공시 원문을 읽는 방식을 설명한다.
- [FRED 서버 (fred)](fred.md) - fred-readonly 서버의 허용 경로 목록, 브리핑용 묶음 도구가 최신값과 변화를 고르는 방식, 순유동성 어림값 계산과 단위 환산, 결측값 처리를 설명한다.
- [한국투자증권 서버 (kis)](kis.md) - kis-readonly 서버의 인증과 조회 흐름, 본문 코드로 오류를 판정하는 방식, 도구 10개의 범위와 입력 처리, 거래소 구분(J·NX·UN)과 실제 조회로 확인한 데이터 기준을 설명한다.
- [한국거래소 서버 (krx)](krx.md) - krx-readonly 서버가 명세 표 하나로 KRX API 31개를 7개 도구로 만드는 구조, 최근 영업일 탐색, 문자열 응답의 값 변환, 서버 쪽 거르기·정렬, 이용신청 오류 안내를 설명한다.
- [토스증권 서버 (toss)](toss.md) - toss-readonly 서버의 OAuth 토큰 재사용, 허용 경로 목록과 입력 검증, 시장 수급을 억원 단위로 요약하는 계산, KRX·NXT 통합 시세 기준에서 오는 제약을 설명한다.
