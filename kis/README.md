# 한국투자증권 MCP 서버 (`kis-readonly`)

한국투자증권(KIS) Open API를 조회 전용으로 제공하는 MCP 서버입니다.

| 항목 | 내용 |
|---|---|
| 버전 | 0.1.1 |
| 대상 API | 한국투자증권 Open API (공식 저장소 `koreainvestment/open-trading-api` 샘플 기준, 2026-11-24 확인) |
| 호출 대상 | `https://openapi.koreainvestment.com:9443` 고정 (실전 도메인) |
| 인증 | appkey, appsecret으로 접근토큰 발급 (`KIS_APP_KEY`, `KIS_APP_SECRET`) |
| 런타임 | Node.js 18 이상, 외부 패키지 없음 |

> **검증 상태**: 2026-11-24 저녁(20:51~21:00)에 실전 서버에서 도구 10개를 모두 조회해 확인했습니다. 장중 동작은 아직 확인하지 않았습니다.

## 도구

| 도구 | 설명 |
|---|---|
| `kis_stock_price` | 국내 종목 현재가. 거래소를 KRX 단독·NXT·통합 중에서 선택 |
| `kis_stock_daily_chart` | 국내 종목 일·주·월·년봉 (한 번에 최대 100건, 수정주가 선택) |
| `kis_stock_minute_chart` | 국내 종목 당일 분봉 (한 번에 최대 30건) |
| `kis_index_price` | 국내 업종지수 현재값 (0001 코스피, 1001 코스닥, 2001 코스피200) |
| `kis_index_daily_chart` | 국내 업종지수 일·주·월·년봉 (한 번에 최대 50건) |
| `kis_market_investor_daily` | 코스피·코스닥 시장별 투자자 순매수 (일별, 수량 천주·금액 백만원) |
| `kis_stock_investor_daily` | 종목별 투자자 매매동향 (일별, 수량 주·금액 백만원) |
| `kis_credit_balance_daily` | 종목 신용잔고 일별 추이 (한 번에 최대 30건) |
| `kis_overseas_price` | 해외 종목 현재체결가 |
| `kis_overseas_daily_chart` | 해외지수·환율·국채·금선물 일·주·월·년봉 (예: 다우 `.DJI`, 원/달러 `FX@KRW`) |

국내 종목 도구의 `market`은 `J`(KRX 단독, 기본값), `NX`(넥스트레이드), `UN`(KRX+NXT 통합)입니다. 날짜는 `YYYY-MM-DD`로 넣으면 KIS 형식으로 바꿔 보냅니다. 응답은 KIS 원본 항목명(`stck_prpr` 등)을 그대로 돌려주며 숫자는 문자열입니다. 수급과 신용잔고는 KIS가 한 번에 30~300일치를 주므로 `count`만큼만 잘라 돌려줍니다.

## 설치

### 인증 정보 발급

[KIS Developers](https://apiportal.koreainvestment.com)에서 Open API 서비스를 신청하고 **실전투자용** appkey와 appsecret을 발급받습니다. 이 서버는 실전 도메인만 호출하므로 모의투자용 키는 쓸 수 없습니다. 실계좌에 연결된 키이므로 외부에 노출하지 마세요.

### MCP 클라이언트에 등록

```json
{
  "mcpServers": {
    "kis": {
      "command": "node",
      "args": ["/path/to/finance-api-hub/kis/server/index.js"],
      "env": { "KIS_APP_KEY": "...", "KIS_APP_SECRET": "..." }
    }
  }
}
```

### Claude Desktop 확장

1. `./pack.sh`를 실행해 `kis-readonly.mcpb`를 만듭니다.
2. 파일을 Claude Desktop의 설정 > 확장 프로그램에 끌어다 놓습니다.
3. 설치 화면에 appkey와 appsecret을 입력하고 확장을 사용 상태로 바꿉니다.

## API 지원 범위

한국투자증권 Open API 334개 중 국내주식·해외주식 시세 조회 10개를 도구로 제공합니다. 주문·계좌 73개는 조회 전용 원칙에 따라, 실시간시세 60개는 웹소켓 방식이라 코드에 포함하지 않았습니다. 선물옵션·ELW·채권·ETF는 범위 밖입니다. 전체 목록과 상태는 [API_CHECKLIST.md](API_CHECKLIST.md)에 있습니다.

한국투자증권은 주문까지 가능한 공식 MCP(`Kis Trading MCP`)를 [공식 저장소](https://github.com/koreainvestment/open-trading-api)에서 배포합니다. 이 서버는 그와 별개로, 조회만 필요할 때 쓰는 용도입니다.

## 보안

- `server/index.js`의 `READ_ENDPOINTS`에 등록된 GET 경로만 호출합니다. POST는 접근토큰 발급(`/oauth2/tokenP`)에만 씁니다.
- 계좌번호를 받지 않으며, 잔고·주문 관련 주소와 tr_id는 코드에 없습니다.
- appkey와 appsecret은 환경변수로만 받습니다. KIS는 조회할 때마다 두 값을 요청 헤더로 보내도록 요구하므로 고정된 KIS 주소로만 전송합니다.
- 접근 토큰은 `~/.kis-mcp/token-*.json`(권한 600)에 캐시합니다. KIS는 토큰을 발급할 때마다 알림톡을 보내고 1분당 1회만 발급하므로, 만료(1일) 전까지 재사용합니다.
- 실행 로그는 `KIS_MCP_LOG_FILE`을 지정했을 때만 남기며(Claude Desktop 확장은 `~/.kis-mcp/server.log`), 인증 정보는 기록하지 않습니다. 오류 문구에서도 키와 토큰을 가립니다.

## 데이터 기준과 제약

2026-11-24 실제 조회로 확인한 내용입니다.

- **지난 영업일 종가**: `kis_stock_daily_chart`에서 `J`의 종가는 KRX 정규장 공식 종가이고, `NX`·`UN`의 종가는 NXT 애프터마켓 마지막 체결가입니다 (삼성전자 11/23: `J` 177,500, `NX`·`UN` 180,600).
- **당일 값은 `J`도 장 마감 뒤 바뀜**: 20:51에 조회한 `J` 현재가와 당일 일봉 종가는 182,900이었고, 같은 날 15:30 분봉은 189,400이었습니다. 당일 정규장 종가가 필요하면 분봉의 15:30 봉을 보거나 다음 영업일에 일봉을 조회하세요. 당일 행이 언제 공식 종가로 바뀌는지는 확인하지 못했습니다.
- **거래량은 거래소별**: `J`와 `NX`의 거래량을 더하면 `UN`과 같습니다.
- **종목별 수급은 거래소별로 분리**: `kis_stock_investor_daily`에서 `J`와 `NX`의 순매수 수량을 더하면 `UN`과 정확히 일치했습니다 (삼성전자 11/24 외국인: `J` 2,348,072주, `NX` 330,195주, `UN` 2,678,267주). 금액은 백만원 단위로 반올림돼 ±1백만원 차이가 날 수 있습니다.
- **종목별 수급의 당일 자료는 15:40 이후**: `kis_stock_investor_daily`에 당일을 `date`로 주면 00:00~15:40에는 KIS가 오류(`OPSQ2001 TIME LIMIT 00:00 ~ 15:40`)를 줍니다(2026-11-25 00:03 확인). `date`를 생략하면 한국 시각 15:40 전에는 전일, 이후에는 당일을 기준일로 조회하고, 전일로 조회했을 때는 응답의 `date`와 `note`로 알립니다. 당일을 직접 지정해 제한에 걸리면 날짜를 바꾸지 않고 안내와 함께 오류를 돌려줍니다. 기준일이 휴장일이면 직전 영업일부터 옵니다. `kis_market_investor_daily`와 `kis_credit_balance_daily`에는 이 제한이 없었습니다.
- **시장 전체 수급은 거래소 구분 없음**: `kis_market_investor_daily`가 쓰는 API는 `J`·`NX`·`UN`을 받지 않습니다. 11/24 코스피 외국인 순매수는 8,046억으로, 같은 날 뉴스의 유가증권시장 수치(7,255억~7,392억, 장 마감 무렵)에 가깝고 토스의 통합 값(1조 1,468억)보다 작았습니다. KRX 단독 기준으로 보이지만 공식 문서로 확인한 것은 아닙니다. 통합 기준 시장 수급은 toss를 쓰세요.
- **단위**: 시장별 투자자는 수량 천주·금액 백만원, 종목별 투자자는 수량 주·금액 백만원입니다. 업종지수의 거래량은 천주, 거래대금은 백만원입니다.
- **신용잔고는 결제 기준**: 최신 행이 2영업일 전 매매분입니다.
- **건수 제한**: 종목 기간별 시세는 한 번에 최대 100건, 업종지수는 50건, 분봉은 30건입니다. 기간이 더 길면 최근 쪽만 오므로 날짜를 나눠 조회합니다. 분봉은 당일 자료만 제공됩니다.
- **없는 종목코드**: KIS는 없는 종목에도 0으로 채운 정상 응답을 줍니다. 현재가 도구는 이를 오류로 바꿔 돌려줍니다.
- **호출 한도**: 60ms 간격(초당 16건쯤)으로 보내면 한도 초과 응답(HTTP 500, `EGW00201`)이 났습니다. 서버는 110ms 간격으로 한 건씩 보내고, 그래도 한도 초과가 오면 1초 기다렸다 한 번 다시 시도합니다.
- **오류 형식**: KIS는 HTTP 200으로 응답하면서 본문의 `rt_cd`로 실패를 알리는 경우가 있습니다(예: 잘못된 거래소코드). 이때 `msg_cd`와 `msg1`을 오류로 돌려줍니다.
- 항목별 반영 시각은 [DATA_TIMING.md](../DATA_TIMING.md)를 참고하세요.
